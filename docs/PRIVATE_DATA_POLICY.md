# PRIVATE DATA POLICY

Публичный GitHub Pages означает, что код репозитория потенциально публичен.

Не помещать в Git:
- реальные пароли;
- service account JSON;
- Zoom join links/passcodes;
- приватные заметки;
- real student seed fixtures;
- ученические работы;
- secret backend/API keys.

Допустимо:
- Firebase web config;
- collection names;
- schema/types;
- UI;
- Security Rules.

Реальные данные — в Firestore под Auth + Rules.
Demo fixtures — только вымышленные.
